# Create the strict DescribeData tool

Create the strict DescribeData tool

## Usage

``` r
describe_data_tool(shield)
```

## Arguments

- shield:

  A
  [`data_shield()`](https://kaipingyang.github.io/codeagent/reference/data_shield.md)
  state containing registered datasets.

## Value

An [`ellmer::tool()`](https://ellmer.tidyverse.org/reference/tool.html).
