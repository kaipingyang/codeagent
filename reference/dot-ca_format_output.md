# Format and print agent output.

Format and print agent output.

## Usage

``` r
.ca_format_output(x, output_fmt = "text", session_id = NULL)
```

## Arguments

- x:

  Character scalar (agent response).

- output_fmt:

  Character. "text" (default) or "json".

- session_id:

  Character or NULL. Included in JSON output.
